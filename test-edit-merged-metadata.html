✏️ Test: Edit Merged Assessment Metadata

This page documents the new feature for editing merged assessment metadata (application name and interview name).

Feature Overview

Purpose: Allow users to edit the application name and interview name of merged results after creation.

Use Case: When a merged result is created with incorrect or generic names, users can now update them without recreating the entire merged result.

Changes Made

1. Updated Create Merged Result Modal

  • Before: Single field "Result Name" that stores in name field
  • After: Two separate fields:
    • Application Name - stored in name field
    • Interview Name - stored in interviewName field

2. Added Edit Button for Merged Results

  • Previously, merged results only had a "View Results" button
  • Now merged results have both:
    • ✏️ Edit button - opens the edit metadata modal
    • 📊 View Results button - navigates to Results tab

3. New Edit Merged Metadata Modal

  • Modal ID: edit-merged-modal
  • Contains two input fields:
    • Application Name (required)
    • Interview Name (required)
  • Validates that both fields are not empty
  • Saves changes and updates file name if using folder sync

4. Updated Display Logic

  • Saved Assessments List: Shows "App Name - Interview Name" for merged results
  • Results Tab Metadata: Displays both fields separately:
    • Application Name: [value]
    • Interview Name: [value]
  • Results Dropdown: Shows "App Name - Interview Name 🔀 [Merged] (date)"

Manual Testing Instructions

Prerequisites

  1. Open index.html in a browser
  2. Create at least 2 sample interviews with different answers

Test 1: Create Merged Result with New Fields

  1. Go to the Data tab
  2. Click "🔀 Create Merged Result" button
  3. You should see two input fields:
    • Application Name
    • Interview Name
  4. Enter values:
    • Application Name: "MyApp"
    • Interview Name: "Q1 2024 Combined"
  5. Select at least 2 interviews
  6. Click "Create Merged Result"
  7. Expected: Success message shows "MyApp - Q1 2024 Combined"

Test 2: View Merged Result Display

  1. Go to Interview tab
  2. Scroll to Existing Interviews
  3. Find the merged result (has 🔀 badge)
  4. Expected:
    • Name shows as "MyApp - Q1 2024 Combined"
    • Has two buttons: "✏️ Edit" and "📊 View Results"

Test 3: Edit Merged Result Metadata

  1. Click the "✏️ Edit" button on a merged result
  2. Expected: Modal opens with two pre-filled fields
  3. Change the values:
    • Application Name: "MyNewApp"
    • Interview Name: "Updated Assessment"
  4. Click "Save Changes"
  5. Expected:
    • Success message appears
    • List updates to show "MyNewApp - Updated Assessment"

Test 4: Validation

  1. Click "✏️ Edit" on a merged result
  2. Clear the Application Name field
  3. Click "Save Changes"
  4. Expected: Alert: "Please enter an application name"
  5. Fill in Application Name but clear Interview Name
  6. Click "Save Changes"
  7. Expected: Alert: "Please enter an interview name"

Test 5: Results Tab Display

  1. Go to Results tab
  2. Select a merged result from dropdown
  3. Expected: Metadata section shows:
    • Type: 🔀 Merged Result
    • Application Name: MyNewApp
    • Interview Name: Updated Assessment
    • Created: [timestamp]

Success Criteria

✅ Merged results can be created with separate app name and interview name
✅ Merged results display both names in the format "App Name - Interview Name"
✅ Edit button appears for merged results

Notes

  • Backward compatibility: Existing merged results with empty interviewName will still work, showing only the app name
  • The edit functionality is similar to the existing rename modal for regular assessments
  • File name generation includes both names when both are provided
