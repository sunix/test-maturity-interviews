✏️ Demo: Edit Merged Assessment Metadata

This page demonstrates the new feature that allows editing application name and interview name for merged assessments.

🎯 Feature Highlights

✅ New Capability: Merged assessments now support both "Application Name" and "Interview Name" fields, and both can be edited after creation!

❌ Before

  • Single field: "Result Name"
  • No interview name field
  • Cannot edit after creation
  • Only "View Results" button

✅ After

  • Two fields: "Application Name" + "Interview Name"
  • Displays as "App - Interview"
  • Can edit both fields anytime
  • Both "Edit" and "View Results" buttons

🔄 User Workflow

Step 1: Create Merged Result

Location: Data tab → "🔀 Create Merged Result" button

New Fields:

  • Application Name - The app/project being assessed (e.g., "MyApp", "E-commerce Platform")
  • Interview Name - Description of this merged assessment (e.g., "Q1 2024 Combined", "Full Team Assessment")

Example:

  • Application Name: E-commerce Platform
  • Interview Name: Q1 2024 All Teams
  • Select: ☑ Frontend Team, ☑ Backend Team, ☑ QA Team

Result: Merged assessment created with name "E-commerce Platform - Q1 2024 All Teams" 🔀 Merged

Step 2: View in Interview List

Location: Interview tab → Existing Interviews

Display:

🔀 Merged E-commerce Platform - Q1 2024 All Teams
Created: 1/22/2026 | Questions: 45 | Sources: 3 interviews

Step 3: Edit Metadata

Action: Click the ✏️ Edit button

Modal Opens With:

  • Application Name:
  • Interview Name:

Example Edit:

  • Application Name: E-commerce Platform → Payment Service
  • Interview Name: Q1 2024 All Teams → Complete Assessment

Save Changes: Click "Save Changes" button

Result: Name updated to "Payment Service - Complete Assessment"

Step 4: View Updated Result

Location: Results tab

Metadata Display:

Assessment Information

Type: 🔀 Merged Result

Application Name: Payment Service

Interview Name: Complete Assessment

Created: 1/22/2026, 2:18:04 PM

Source Interviews (3):

  • E-commerce Platform - Frontend Team
  • E-commerce Platform - Backend Team
  • E-commerce Platform - QA Team

🛡️ Validation

Both fields are required:
  • Empty Application Name → Alert: "Please enter an application name"
  • Empty Interview Name → Alert: "Please enter an interview name"

💾 File Management

Folder Sync Integration:
  • When you edit metadata, the file name in your sync folder is automatically updated
  • Old file is deleted, new file is created with updated name
  • Format: assessment-{appName}-{interviewName}-{date}.json
  • Example: assessment-PaymentService-CompleteAssessment-2026-01-22.json
