🧪 Merged Results Test

This page tests the functionality for merging multiple interviews into a single result with averaged scores.

Feature Overview

Purpose: Allow users to create a single combined result from multiple interviews.

Use Case: When conducting interviews with multiple teams (Frontend, Backend, QA) for the same application, users can merge these into one comprehensive assessment showing averaged scores.

Scoring Logic: For questions answered in multiple interviews, the system calculates an average score. If the average is ≥ 0.5 (50%), the merged answer is "Yes", otherwise "No".
